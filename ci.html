What these checks are, and are not

Plain answers.

What they cover

  • The Rust workspace: the permission engine, the payment engine, the data gateway, the platform server and the SQL reader, including the written attacks.
  • The web dashboard and the two SDKs (TypeScript and Python), including checks that both sign requests byte for byte the same way.
  • A clean compiler and a strict linter. Warnings count as failures.

What they do not prove

  • That anyone wants the product. These are tests, not customers.
  • That the system is secure against someone we did not think of. No independent security review has happened.
  • That it works against a production database or a live payment provider. It has not been run against either.

The script is scripts/ci-local.py in the source. The raw report is files/ci-report.json. Source access is available under NDA to a reviewer, who can run the same script.
